A dashboard-style personal website where I publish essays and showcase work — built so I can add new posts from a browser editor without touching code.

## Highlights

- Static-fast Astro build deployed on Netlify.
- Visual content editor at `/admin` (write posts, hit publish).
- Brand-driven design system in the Niko palette.

## What I learned

Designing a content model that's pleasant to *write* in matters as much as how it looks to readers.
